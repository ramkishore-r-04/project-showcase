# 👥 HR Analytics Dashboard

An interactive **Power BI HR Analytics Dashboard** designed to help organizations analyze workforce data, monitor employee performance, and identify key factors influencing employee attrition and retention.

---

## 📌 Project Overview

This dashboard provides actionable HR insights by transforming employee data into interactive visualizations. It enables HR professionals and business leaders to make informed decisions regarding workforce planning, employee engagement, and retention strategies.

---

## 🎯 Objectives

- Analyze employee demographics
- Monitor employee attrition
- Identify workforce trends
- Evaluate job satisfaction and performance
- Support data-driven HR decision-making

---

## 📊 Dashboard Features

- 📈 Employee Overview
- 👨‍💼 Department-wise Analysis
- 📉 Attrition Analysis
- 💰 Salary Distribution
- 🎓 Education & Job Role Analysis
- 👥 Gender Distribution
- 📅 Age Group Analysis
- ⭐ Job Satisfaction Metrics
- 📍 Interactive Filters and Slicers

---

## 🛠️ Tools & Technologies

- Power BI
- Power Query
- DAX
- Microsoft Excel / CSV Dataset
